단계를 선택하면 입력·처리·출력과 중단 경계를 확인할 수 있습니다.

01 — FLOW

STEP 01 / FETCH

공개된 작업별 점유율만 읽습니다.

OpenRouter 공식 Data API의 작업별 분류 결과(7일 창)와 모델 카탈로그를 GET으로 읽습니다. 각 작업의 상위 모델에는 요청 점유율과 토큰 점유율이 함께 제공되며, 이 도구는 기본으로 요청 점유율을 사용합니다.

입력
작업별 7일 점유율 응답 · 모델 카탈로그 응답
처리
스키마와 7일 창 확인 · 원본 날짜 유효기간(기본 72시간) 검사 · 점유율 범위 검증
출력
작업 태그별 모델 점유율 표와 출처 표시 문구
데이터 경계

이 API는 프롬프트를 분류해 주는 API가 아니며, Auto Router 내부 지출 순위를 반환하는 API도 아닙니다. 응답이 오래되었거나 형식이 다르면 갱신을 중단하고 기존 프리셋을 유지합니다.

STEP 02 / EXACT MATCH

이미 등록되고 허용된 모델만 연결합니다.

정책의 허용 목록에 있는 로컬 selector가 실제 models.yml에 유일하게 등록되어 있는지 먼저 확인합니다. 그 다음 전체 OpenRouter ID가 같거나, 로컬 모델 ID가 vendor를 제거한 OpenRouter ID와 유일하게 일치할 때만 연결을 인정합니다.

입력
허용 selector 목록 · 로컬 모델 등록 정보 · 카탈로그
처리
정확한 ID 일치 확인 · 다중 vendor 충돌 시 명시 alias 요구
출력
연결된 후보 목록과 제외 사유(not_registered, unmapped_or_ambiguous)
신원 경계

유사 이름, 버전 교체, 와이어 호환성을 추측하지 않습니다. 새로 출시된 모델은 카탈로그에 나타나도 로컬 등록·허용 목록에 없으면 자동으로 도입하지 않습니다.

STEP 03 / FILTERS

도구, 컨텍스트, 참조 가격을 검사합니다.

도구 호출 지원은 OpenRouter의 지원 파라미터와 로컬의 명시적 비호환 설정을 함께 봅니다. 최소 컨텍스트는 카탈로그 값과 로컬 contextWindow가 모두 알려져 있고 충분해야 통과합니다. 참조 가격 상한은 OpenRouter 카탈로그의 입력·출력 단가(USD/백만 토큰)에 적용됩니다.

입력
후보별 카탈로그 정보 · 로컬 모델 메타데이터 · 정책 filters
처리
require_tools · min_context · max_prompt_per_million · max_completion_per_million
출력
조건을 통과한 후보와 제외 사유(capability_or_reference_price_filter)
가격 경계

참조 가격은 실제 로컬 구독 과금이나 잔여 쿼타가 아닙니다. 가격 상한을 설정한 항목의 단가가 알려지지 않으면 해당 후보를 제외합니다.

STEP 04 / WEIGHTED AVERAGE

역할마다 작업 가중치로 평균을 냅니다.

가중 점유율은 새 후보를 소수로 추리는 지표입니다. 실제 적용은 역할별 본평가 증거를 별도로 검사하며, 유효한 기존 모델의 증거는 재사용합니다. 새 모델이 나왔다고 전체 평가를 다시 실행하지 않습니다.

입력
조건을 통과한 후보 · 역할별 작업 가중치 · 작업별 점유율 표
처리
유효 증거 재사용 · 별도 승인 아래 선별/본평가 · 기간별 실행 예산 제한 · 본평가 우선, 점유율은 동점 처리 · incumbent 비교 · 전체 chain 검사
출력
역할별 primary/fallback 배열
해석 경계

점유율 가중평균은 인기 지표이지 품질 지표가 아닙니다. 어떤 역할이든 매칭 태그가 없거나 후보가 비면 부분 업데이트 없이 전체 갱신을 중단합니다.

STEP 05 / PREVIEW

미리보기는 모델 설정을 바꾸지 않습니다.

plan과 sync는 기본적으로 계산 결과와 제외 사유만 보고합니다. 보고서에는 사용한 지표, 원본 날짜, 출처 표시, 역할별 후보 점수, 그리고 추론 호출 수 0이 포함됩니다.

입력
역할별 후보 배열 · 현재 설치된 관리 프리셋
처리
변경 예정 내용과 제외 사유 정리 · OpenRouter 출처(CC BY 4.0) 표시 보존
출력
미리보기 보고서 · models.yml 변경 없음
변경 경계

미리보기도 데이터 GET 요청과 비공개 캐시·보고서 파일 기록을 수행할 수 있습니다. 변경하지 않는 대상은 모델 설정이며, 관리 프리셋 반영에는 명시 적용 옵션이 필요합니다.

STEP 06 / APPLY & ROLLBACK

명시 적용은 도구 소유 프로필만 기록합니다.

sync --apply는 정책에 지정된 or-* 이름의 관리 프로필 하나만 기록합니다. GJC의 잠금 규약에 참여하고, 쓰기 직전 원문을 재검사하며, 원자적 교체와 미완료 기록 복구를 사용합니다. rollback --apply는 관리 프로필만 기록된 이전 상태로 되돌립니다.

입력
미리보기와 동일한 후보 배열 · 명시 적용 옵션
처리
원본 백업 · 잠금 협력 · profiles 섹션만 재작성 · 나머지 섹션은 바이트 그대로 보존
출력
갱신된 관리 프로필 하나 · 상태와 백업 기록
소유 경계

관리하지 않는 프로필의 의미와 providers 등 다른 섹션을 보존하며, config.yml·기본 선택·실행 중 세션의 모델은 바꾸지 않습니다. profiles 안의 주석과 서식은 재배치될 수 있습니다. 다른 프로세스가 관리 프로필을 수정했으면 중단합니다. 전체 백업에는 기존 비밀 값이 포함될 수 있으므로 외부에 공유하지 않아야 합니다.

WHAT IT IS NOT

같아 보이지만 다른 것들

이 도구가 주장하지 않는 것을 먼저 구분합니다.

02 — DISTINCTIONS
A / SHARE ≠ QUALITY

점유율은 품질이 아닙니다

작업별 점유율은 그 기간에 얼마나 많이 선택되었는지를 나타냅니다. 상위 모델이 더 좋은 답을 낸다는 주장으로 읽지 않습니다.

보고서에도 벤치마크나 공식 라우터 재현이 아니라고 명시합니다.

B / REQUEST · TOKEN ≠ SPEND

요청·토큰 점유율은 지출이 아닙니다

공식 API가 제공하는 값은 요청 점유율과 토큰 점유율입니다. 이를 지출 점유율로 계산하거나 위장하지 않습니다. 별도로 검증한 지출 스냅샷은 운영자가 명시적으로 가져올 때만 사용합니다.

지출 데이터의 자동 수집 어댑터는 제공하지 않습니다.

C / ZERO INFERENCE ≠ FREE

추론 호출 0회가 전체 무료를 뜻하지 않습니다

갱신 코드는 모델 추론을 호출하지 않습니다. 그러나 데이터 API 호출의 과금 여부를 추정해 무료라고 단정하지 않으며, 생성된 프리셋으로 GJC를 실행하면 기존 연결의 한도·요금·제공자 정책이 그대로 적용됩니다.

비용에 대한 판단은 운영자의 실제 계약과 계정 기준입니다.

범위 안내

이 도구는 GJC 본체나 서명된 공식 preset registry를 수정하지 않습니다. 사용자 models.yml의 도구 소유 profiles 항목 하나만 관리하며, 새 API 제공자나 인증 저장소를 만들지 않습니다. 데이터 조회에는 운영자가 환경 변수로 제공한 OpenRouter 키를 사용합니다. 이 소개 페이지는 키를 읽거나 입력받지 않습니다.

HOW THE SCORE IS FORMED

가중평균 계산 방식 데모

가상 점유율로 후보 탐색 계산만 보여 줍니다. 품질 검사·승격 결과, 실측 데이터, 추천, 현재 순위가 아닙니다. 별도 평가기의 실행·시간 제한도 금액 상한을 보장하지 않습니다.

↳

유효한 후보가 없으면
갱신하지 않습니다.

개별 모델의 연결·조건 검사 실패는 해당 후보의 제외로 처리합니다. 어떤 역할이든 후보가 비거나 데이터가 오래되었을 때, 잠금 충돌·관리 프로필 수정이 확인되었을 때는 전체 갱신을 중단합니다.

같은 짧은 ID가 여러 vendor에 있으면?+

연결을 인정하지 않고 unmapped_or_ambiguous로 제외합니다. 정책의 alias에 정확한 OpenRouter ID를 명시해야 합니다.

어떤 역할에 매칭되는 작업 태그가 없으면?+

부분 프리셋을 만들지 않고 전체 갱신을 중단합니다. 설치된 프리셋은 그대로 남습니다.

원본 날짜가 유효기간을 넘었으면?+

유효기간을 초과하거나 허용된 미래 시각 오차(1시간)를 넘은 스냅샷은 거부합니다. 기본 유효기간은 72시간이고 기본 캐시는 6시간입니다.

다른 프로세스가 잠금을 잡고 있으면?+

GJC의 잠금 규약을 따르며 다른 잠금을 임의로 제거하거나 탈취하지 않습니다. 소유 프로세스를 운영자가 확인해야 합니다.

백업에는 무엇이 들어가나?+

생성 전 원본 models.yml 전체를 소유자 전용 권한으로 보관합니다. 기존 비밀 값이 포함될 수 있으므로 외부 공유나 커밋 대상이 아닙니다.

profiles 섹션의 주석과 서식은 유지되나?+

profiles 외 섹션은 바이트 그대로 보존합니다. profiles 섹션 안의 주석·서식은 재직렬화로 재배치되거나 사라질 수 있으며, 앵커·별칭·중복 키가 있는 파일은 잘못 수정하지 않도록 거부합니다.
